1. KARAR: TEK DOSYA, ÇOK MODÜL
--------------------------------------------------------------------------------
Executor'lar tek URL çeker: loadstring(game:HttpGet(url))(). Bu yüzden dağıtım
TEK dosya. Ama 3.700 satırı tek dosyada elle yazmak bakımı imkansız kılar.

Çözüm:
  src/           27 modül, her biri tek sorumluluk
  tools/build.py modülleri bağımlılık sırasına göre birleştirir
  dist/basalt.luau  tek dosya, ~3.750 satır, 89 KB, sıfır dış bağımlılık

Build çıktısı kendi özel `require`'ını taşır; kullanıcı modül görmez.
WindUI, Fluent, Rayfield de aynı modeli kullanır (kaynak modüler, çıktı tek).

3. NEDEN BÖYLE
--------------------------------------------------------------------------------
3.1 Flag sahipliği
    Kontrol değeri tutmaz; flag tutar. Kontrol yazar, flag sinyal verir, kontrol
    çizer. Config yüklerken de aynı yol işler; ekran ile dosya asla ayrışmaz.
    (Fluent'in Options modeli; bizde Key = string.)

3.2 Tema bağlama
    Her renk Theme:Bind(gui, "TextColor3", "text") ile bağlanır. Tema değişince
    yalnız bağ listesi gezilir. WindUI/NeverLose'un GetDescendants + renk
    eşleştirme yöntemi kırılgan ve yavaş; Basalt'ta yok.

3.3 Layout
    Section yükseklikleri UIListLayout + AutomaticSize ile ölçülür. Sekme
    gövdesi iki sütunun maksimumu; reflow yalnız içerik boyutu değişince ve
    50 ms debounce ile çalışır. Heartbeat döngüsü yok.

3.4 Tek dosya çıktı
    Modüler kaynak + deterministik build. Modül sırası build.py'de açıkça
    yazılıdır; gizli sihir yok.

3.5 Hata izolasyonu
    Her callback pcall içinde. Bozuk bir kullanıcı callback'i arayüzü kilitlemez.

4. API (özet)
--------------------------------------------------------------------------------
local Basalt = loadstring(game:HttpGet(".../dist/basalt.luau"))()

local win = Basalt:Window{
    Title = "Basalt", Size = UDim2.fromOffset(760, 500),
    Theme = "basalt-dark", ToggleKey = Enum.KeyCode.RightShift,
    Autosave = "main",
}

local tab = win:Tab{ Title = "Combat" }
local sec = tab:Section{ Title = "Aim", Column = "left" }

sec:Toggle{ Key = "aim", Title = "Enabled", Description = "Silent aim", Default = false }
sec:Slider{ Key = "smooth", Title = "Smoothing", Min = 0, Max = 1, Rounding = 2 }
sec:Range { Key = "fov", Title = "FOV", Min = 0, Max = 180, Default = {40,120} }
sec:Dropdown{ Key = "part", Title = "Target", Values = {"Head","Torso"} }
sec:Keybind{ Key = "key", Title = "Key", Default = Enum.KeyCode.Mouse4 }
sec:Input  { Key = "name", Title = "Profile", Placeholder = "main" }
sec:Colorpicker{ Key = "accent", Title = "Accent" }
sec:Button { Title = "Save", Variant = "primary", Callback = function() end }
sec:Paragraph{ Text = "..." }
sec:Divider()

Basalt.Flags:OnChanged("smooth", function(v) print(v) end)
Basalt.Config:Save("main"); Basalt.Config:Load("main")
win:Notify{ Title = "Ready", Content = "loaded", Type = "success", Duration = 4 }
win:SetTheme("basalt-dusk")

5. TASARIM KURALLARI (design rule.txt)
--------------------------------------------------------------------------------
- Tek vurgu rengi: accent. Durum renkleri yalnız durum için.
- Boşluk ölçeği 4/8/12/16/24/32; kontrol yüksekliği 32 (mobilde 36).
- Yarıçap: pencere 10, bölüm 8, kontrol 6.
- Gradient, blur, glow, dekoratif gölge yok (varsayılan temada).
- Durumlar: default / hover / active / focus / disabled / error.
- Tipografi: Segoe UI (Roblox'ta Gotham ailesi), 14 / 13 / 12 / 11 / 10.
- "Süs" olan hiçbir şey yok; her eleman bir işi karşılıyor.
